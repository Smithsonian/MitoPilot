# Get assembly from database (user-supplied assemblies)

Deprecated: identical to \[get_assembly()\], which serves both project
types.

## Usage

``` r
get_assembly_userAsmb(ID, path, scaffold = NULL, con)
```

## Arguments

- ID:

  sample ID

- path:

  assembly getOrganelle path

- scaffold:

  scaffold name(s) to get (NULL for all, default)

- con:

  database connection
